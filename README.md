# Stock Tracker

## About the Project
A simple Python-based Stock Tracker that calculates the total value of owned shares and saves transaction records to a CSV file.

## Features
- Supports multiple stock tickers.
- Calculates stock value using price × shares owned.
- Displays a formatted financial summary.
- Validates ticker symbols and share quantities.
- Saves transactions with timestamps to a CSV file.

## Technologies Used
- Python 3
- CSV module
- File handling
- Dictionaries, loops, and functions

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python stock_tracker.py
```

## Note
The stock prices are predefined sample values and are not live market prices. This project is for educational purposes only.
